# 헤드라인 프레임 라벨링

뉴스 제목마다 **메인 프레임** 하나를 붙이고, 정말 두 프레임이 대등할 때만 **서브 프레임**을 하나 더 붙인다. 프레임을 정한 단어는 근거로 남긴다. 분류는 Claude가 제목을 직접 읽고 판단한다. 코드는 파일 읽기, 검사, 저장, 표 만들기에만 쓴다.

판단의 바탕은 Entman(1993)의 정의다. 프레이밍은 현실의 어떤 측면을 골라 더 두드러지게 만드는 것이므로, 같은 사건의 모든 언론사가 공통으로 쓰는 **기본 사실**을 빼고 남는 표현이 그 제목의 프레임이다. 단, 사건 자체가 문제에 대한 대책 발표이면 추가 규칙 6을 따른다.

## 입력과 출력

- 입력: `headlines.csv` — 열 `id, 일자, 언론사, 유형, 제목, 사건`
- (선택) `basefacts.csv` — 열 `사건, 기본 사실`. 없으면 1단계에서 만든다.
- 출력: `labeled.csv` — 입력 열 그대로 + `메인 프레임`, `메인 근거`, `서브 프레임`, `서브 근거` (UTF-8 with BOM, 엑셀에서 한글이 깨지지 않게). 서브가 없으면 두 서브 열은 비운다.
- (선택) 기준 라벨 파일: 예) `헤드라인_프레임_주간.xlsx`의 `헤드라인 라벨` 시트, `Claude 프레임` 열

열이 하나라도 없으면 멈추고 어떤 열이 빠졌는지 알려준다.

## 프레임 7개

| 프레임 | 정의 | 단서 표현 |
| --- | --- | --- |
| 사실 전달 | 기본 사실 말고는 남는 표현이 없음 (대책 발표 사건은 추가 규칙 6) | 의결, 상정, 추진, 비자 발급, 강화안 발표 |
| 갈등 | 행위자 사이의 대립과 반발을 앞세움 | 강행, 반발, 퇴장, 대치, 항의, 상대를 비판하는 인용 |
| 원인·책임 | 이유나 책임 주체를 밝힘. 원인 연결어나 책임 주체가 제목에 있을 때만 | ~에, ~로, ~후, 영향, 반영, 후폭풍, 책임 규명 |
| 부정 결과·우려 | 손실, 위험, 대가, 고통을 앞세움 | 급락, 뜀박질, 거액 반환, 뒤늦게, 절망감, 비상, 주의보, "손 떨려 진료 못 해" |
| 긍정 성과 | 기록, 회복, 혜택을 앞세움 | 역대 최대 실적, 첫 돌파, 회복, 다행 |
| 대응·조치 | 문제를 막거나 수습하려는 대책을 앞세움 | 체불 막는다, 부정행위 형사고발, 응시정지, 사과, 협의 |
| 기타 | 어느 쪽으로도 보기 어려움 | 사설의 당부 등 |

프레임 이름은 위 표의 글자 그대로 쓴다 (예: `원인·책임`의 가운뎅점 포함).

## 판단 절차

제목마다 아래 세 단계를 따른다. 고정된 프레임 우선순위는 쓰지 않는다.

1. **기본 사실을 지운다.** 그 사건의 기본 사실에 해당하는 말(누가, 무엇을, 수치)을 제목에서 지운다. 대책 발표 사건이면 추가 규칙 6을 먼저 적용한다.
2. **남은 표현을 프레임으로 바꾼다.** 남은 표현마다 어느 프레임인지 본다. 같은 프레임의 표현이 여러 개면 하나의 프레임이다 (예: "강행 / 퇴장" → 갈등 하나).
3. **메인과 서브를 정한다.**
   - 남은 표현이 없으면 → 메인 = 사실 전달
   - 프레임이 하나면 → 메인 = 그 프레임
   - 프레임이 둘 이상이면 → 제목에서 가장 강조된 쪽이 메인이다. 강조는 주절(문장의 중심 서술), 따옴표, 제목 앞쪽 위치로 판단한다. 나머지는 버린다.
   - **서브는 아래 세 조건을 모두 만족할 때만** 하나 붙인다. 이때는 제목에서 앞에 나온 쪽이 메인, 뒤가 서브다.
     1. 두 프레임의 근거 표현이 제목에 따로따로 있다.
     2. 한쪽이 다른 쪽을 꾸미는 말이 아니다 (예: "압수수색 **받은** 교수"처럼 사람·대상을 수식하는 말이면 서브가 아니다).
     3. 주절, 따옴표로 봐도 어느 쪽이 중심인지 갈리지 않는다 (예: 둘 다 따옴표로 강조됨).
   - 서브는 최소화한다. 헷갈리면 서브를 붙이지 않는다. 서브가 붙는 제목은 보통 전체의 20%를 넘지 않는다.

## 추가 규칙

1. 사건 자체를 전하더라도 평가하는 말(결국, 뒤늦게, 다행, "~도 거부당했다")이 붙으면 그 말이 남는 표현이다 → 긍정/부정.
2. 평가어 없이 수치나 사건만 전하면 사실 전달이다. "몇 일 만에"처럼 걸린 기간만 말하는 표현, "무슨 일이?", "이유는?"처럼 답 없는 질문은 남는 표현이 아니다.
3. `메인 근거`, `서브 근거`에는 그 프레임을 정한 단어를 제목에서 글자 그대로 옮겨 적는다. 여러 개면 ` / `로 구분한다. 메인이 사실 전달이면 비운다.
4. 언론사 이름을 보고 판단하지 않는다. 분류할 때는 `id`, `제목`, 그 사건의 기본 사실만 본다.
5. [속보], [사설], [영상] 같은 말머리는 판단에 쓰지 않는다. 단, 사설의 당부("~해야", "~없도록")는 다른 표현이 없으면 기타다.
6. **대책 발표 사건**: 사건 자체가 어떤 문제에 대한 정부·기관의 대책 발표면(예: 수능 스마트안경 처벌, 퇴직연금 사외적립 의무화), 대책 내용을 기본 사실에 넣어 지우지 않는다. 대신 이렇게 나눈다.
   - 제목이 **문제와 대책을 함께** 담으면 → 대응·조치 (예: "부정행위 → 형사고발", "AI안경 쓰면 형사처벌", "체불 막는다"). 문제는 "부정행위", "체불"처럼 이름으로 나오거나 "~쓰면", "~걸리면"처럼 잘못된 행동으로 나온다.
   - 제목이 **대책의 이름이나 절차만** 담으면 → 사실 전달 (예: "퇴직급여 사외 적립 의무화 강화안 발표", "결제주기 단축 로드맵 공개").
   - 대책에 더해 평가어나 원인이 강조돼 있으면(예: "주의보", "비상", "떼일 걱정 끝") 판단 절차 3단계로 메인·서브를 정한다.
   - 이 사건의 `기본 사실`에는 "○○ 대책 발표 (대책 발표 사건)"처럼 표시해 둔다.

## 작업 순서

### 1. 읽고 검사하고, 사건별 기본 사실 정하기

```python
import pandas as pd
COLS = ['id', '일자', '언론사', '유형', '제목', '사건']
df = pd.read_csv('headlines.csv', encoding='utf-8-sig')
missing = [c for c in COLS if c not in df.columns]
assert not missing, f'없는 열: {missing}'
print(len(df), df['사건'].nunique())
for ev, g in df.groupby('사건'):
    print('##', ev, len(g))
    for t in g['제목'].head(15):
        print('  -', t)
```

- `basefacts.csv`가 없으면, 사건마다 제목 여럿을 보고 대부분의 제목이 공통으로 담은 내용(누가, 무엇을, 수치)을 한 줄로 적어 `basefacts.csv`로 저장한다. 평가어나 원인은 넣지 않는다.
- 사건이 어떤 문제에 대한 대책 발표면 기본 사실 끝에 `(대책 발표 사건)`을 붙이고 추가 규칙 6을 적용한다.
- 기본 사실 표를 답변에 먼저 보여준다. 사용자가 대화 중이면 고칠 게 있는지 묻고, 없으면 그대로 진행한다.

### 2. 50건씩 나눠 분류하기

- 묶음마다 `id | 제목`과 그 사건의 기본 사실만 출력해서 읽는다 (언론사는 출력하지 않는다).
- 판단 절차와 예시로 제목마다 정해 `labels.jsonl`에 한 줄에 하나씩 덧붙인다:
  `{"id": 521, "메인 프레임": "부정 결과·우려", "메인 근거": "손 떨려서 못해", "서브 프레임": "원인·책임", "서브 근거": "압수수색"}`
- 서브가 없으면 `"서브 프레임": "", "서브 근거": ""`로 쓴다.
- 한 번에 전체를 맡는 대신 묶음마다 저장해서, 중간에 끊겨도 이어서 할 수 있게 한다.

```python
bf = dict(pd.read_csv('basefacts.csv', encoding='utf-8-sig').values)
for start in range(0, len(df), 50):
    chunk = df.iloc[start:start + 50]
    for ev, g in chunk.groupby('사건', sort=False):
        print('## 기본 사실:', bf.get(ev, ev))
        for _, r in g.iterrows():
            print(r['id'], '|', r['제목'])
    # 여기서 멈추고 이 50건을 분류해 labels.jsonl에 쓴 뒤 다음 묶음으로
```

### 3. 검사하고 저장하기

```python
import json
FRAMES = ['사실 전달', '갈등', '원인·책임', '부정 결과·우려', '긍정 성과', '대응·조치', '기타']
lab = pd.DataFrame([json.loads(l) for l in open('labels.jsonl', encoding='utf-8')]).drop_duplicates('id', keep='last')
out = df.merge(lab, on='id', how='left')
for c in ['메인 근거', '서브 프레임', '서브 근거']:
    out[c] = out[c].fillna('')

def parts(s):
    return [x.strip() for x in s.split('/') if x.strip()]

problems = []
for _, r in out.iterrows():
    m, s = r['메인 프레임'], r['서브 프레임']
    if m not in FRAMES:
        problems.append((r['id'], '메인 프레임 이름 오류 또는 누락'))
        continue
    if s and (s not in FRAMES or s == m):
        problems.append((r['id'], '서브 프레임 이름 오류 또는 메인과 같음'))
    if m == '사실 전달' and (r['메인 근거'] or s):
        problems.append((r['id'], '사실 전달인데 근거나 서브가 있음'))
    if m not in ('사실 전달', '기타') and not r['메인 근거']:
        problems.append((r['id'], '메인 근거 없음'))
    if s and not r['서브 근거']:
        problems.append((r['id'], '서브 근거 없음'))
    for p in parts(r['메인 근거']) + parts(r['서브 근거']):
        if p not in r['제목']:
            problems.append((r['id'], f'근거 "{p}"가 제목에 없음'))
print(problems)
print('서브 비율', f"{(out['서브 프레임'] != '').mean():.0%}")
```

- 문제가 나온 제목만 다시 분류해 `labels.jsonl`에 덧붙이고 검사를 다시 돌린다.
- 서브 비율이 20%를 넘으면 서브가 붙은 제목을 다시 보고, 세 조건을 모두 만족하지 않는 것은 서브를 지운다.
- 문제가 없으면 저장한다: `out.to_csv('labeled.csv', index=False, encoding='utf-8-sig')`

### 4. 사건별 프레임 분포 표

두 가지를 보여준다. 메인 프레임 분포(제목마다 1건씩)와, 메인이든 서브든 그 프레임이 들어간 제목 수다.

```python
t = pd.crosstab(out['사건'], out['메인 프레임']).reindex(columns=FRAMES, fill_value=0)
t['합계'] = t.sum(axis=1)
print(t.sort_values('합계', ascending=False).to_markdown())

long = pd.concat([
    out[['사건', '메인 프레임']].rename(columns={'메인 프레임': '프레임'}),
    out.loc[out['서브 프레임'] != '', ['사건', '서브 프레임']].rename(columns={'서브 프레임': '프레임'}),
])
t2 = pd.crosstab(long['사건'], long['프레임']).reindex(columns=FRAMES, fill_value=0)
print(t2.to_markdown())
```

답변에는 메인 분포 표를 마크다운 표로 보여주고, 서브까지 포함했을 때 값이 크게 달라지는 사건이 있으면 한 줄로 짚는다. 전체 메인 프레임별 건수와 서브가 붙은 제목 수도 한 줄로 덧붙인다.

### 5. (기준 라벨이 있을 때) 일치율 비교

```python
ref = pd.read_excel('헤드라인_프레임_주간.xlsx', sheet_name='헤드라인 라벨')[['id', 'Claude 프레임']]
m = out.merge(ref, on='id', how='inner')
main_agree = (m['메인 프레임'] == m['Claude 프레임']).mean()
any_agree = ((m['메인 프레임'] == m['Claude 프레임']) | (m['서브 프레임'] == m['Claude 프레임'])).mean()
from sklearn.metrics import cohen_kappa_score
kappa = cohen_kappa_score(m['메인 프레임'], m['Claude 프레임'])
print(len(m), f'{main_agree:.1%}', f'{any_agree:.1%}', round(kappa, 3))
print(pd.crosstab(m['Claude 프레임'], m['메인 프레임']).to_markdown())
diff = m[m['메인 프레임'] != m['Claude 프레임']][['id', '사건', '제목', 'Claude 프레임', '메인 프레임', '서브 프레임', '메인 근거']]
print(diff.to_markdown(index=False))
```

- id가 안 맞으면 `제목` 열로 맞춘다.
- 답변에는 비교한 건수, 메인 일치율, 서브까지 포함한 일치율(기준 라벨이 메인이나 서브 중 하나와 같은 비율), Cohen's κ(메인 기준), 혼동 행렬, 다르게 붙은 제목 표를 보여준다. 다른 제목이 30건을 넘으면 표에는 30건만 넣고 전체는 `diff.csv`로 저장한다.
- 가장 자주 엇갈린 프레임 쌍 2–3개를 한 문장씩 설명한다.
- 기준 라벨 `Claude 프레임`은 이전 기준(고정 우선순위, 프레임 1개)으로 Claude가 붙인 것이다. 그래서 이 비교는 정확도가 아니라 **기준을 바꾼 뒤 무엇이 달라졌는지**를 보여주는 것이라고 분명히 적는다. 사람 라벨(팀원A/B/C 열)이 채워져 있으면 그 열과도 같은 방식으로 비교한다.
